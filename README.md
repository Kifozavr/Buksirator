# Буксиратор

Генератор лучевых фонов 1920 × 1080 с эффектом затягивания: палитры, градиенты,
картинка на переднем плане, экспорт картинки и зацикленной анимации на 10 секунд.

- Онлайн: https://claude.ai/artifact/K1wt9C8ckfZ3U8zssX3Snk
- Локально: откройте `Buksirator.html` двойным кликом. Работает без интернета
  (шрифты тогда берутся системные).

## Форматы экспорта

| Формат | Что это | Когда брать |
| --- | --- | --- |
| PNG | Кадр 1920 × 1080 | Статичный фон |
| Живой фон (HTML) | Страница от 13 КБ (с картинкой больше), сама рисует цикл на видеокарте зрителя | Фон на сайте: без потерь, любой размер окна, частота экрана |
| Видео MP4 (H.264) | Файл на 5–30 МБ, играет везде | Соцсети, презентации, `<video>` на сайте |
| Видео WebM (VP9) | То же, примерно на треть легче | `<video>` на сайте, если не нужен старый Safari |
| GIF | 256 цветов, 15–60 МБ | Только там, где видео не принимают |

Вставка на страницу:

```html
<!-- живой фон -->
<iframe src="buksirator.html" style="border:0;width:100%;height:100%" aria-hidden="true"></iframe>

<!-- видео -->
<video src="buksirator.mp4" autoplay loop muted playsinline></video>
```

Что стоит знать:

- Видеокодеки в браузере хранят цвет в половинном разрешении (4:2:0), поэтому границы
  ярких лучей в видео чуть мягче, чем в PNG. Битрейт это не лечит. Нужна точная копия
  картинки на сайте — берите живой фон.
- Живой фон требует WebGL 2. При системной настройке «меньше движения» показывает
  неподвижный кадр, вне экрана и в фоновой вкладке останавливается. Если окно не 16:9,
  сцена обрезается, а центр притяжения остаётся на своём относительном месте.
- Видео кодирует сам браузер (WebCodecs). MP4 доступен в Chrome, Edge и Safari;
  там, где кодировщика H.264 нет, кнопка формата неактивна и остаётся WebM.

## Что где лежит

| Путь | Что это |
| --- | --- |
| `Buksirator.html` | Готовая автономная страница. Собирается скриптом, руками не править. |
| `dist/artifact.html` | Та же страница без обёртки `<html>`, из неё публикуется онлайн-версия. |
| `src/page.html` | Разметка и стили интерфейса. |
| `src/app.js` | Вся логика: палитры, шейдер лучей, градиенты, картинка, анимация, экспорт. |
| `vendor/gifenc.esm.js` | Кодировщик GIF (gifenc 1.0.3, MIT). |
| `vendor/mp4-muxer.min.js`, `vendor/webm-muxer.min.js` | Упаковка видео в MP4 и WebM (Vanilagy, MIT), минифицированы. |
| `build.py` | Сборка: склеивает исходники и библиотеки в две страницы. |

## Как вносить изменения

1. Править `src/app.js` или `src/page.html`.
2. Запустить `python3 build.py` в этой папке.
3. Открыть `Buksirator.html` и проверить.
4. Онлайн-версию обновить из `dist/artifact.html`.

## Где что искать в `src/app.js`

- `PALETTES` — десять палитр. `flow: true` у сложных: соседние лучи берут соседние цвета.
- `DEFAULTS` — предустановка с самым сильным затягиванием и стартовые настройки экспорта.
- `FS` — фрагментный шейдер: изгиб, закрутка, поиск луча, градиент, глубина, волны, картинка.
- `fillEdges`, `effParams`, `applyUniforms` — ядро кадра. Их исходный текст целиком
  вшивается в живой фон, поэтому внутри нельзя ссылаться на внешние переменные.
- `playerMain` — проигрыватель живого фона, `liveHtml` собирает файл.
- `buildGradient` / `mixLch` — чистые градиенты в OKLCH.
- `paletteFromImage` — схема лучей из основных цветов картинки.
- `exportPng`, `exportGif`, `exportVideo`, `exportLive` — экспорт.
- `SLIDERS` — подписи, диапазоны и формат значений всех ползунков.
